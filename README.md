# LocalScribe для Mac

Запись и распознавание речи на вашем Mac, диктовка по клавише и локальная обработка текста.

## ⬇️ [Скачать LocalScribe для Mac](https://github.com/Yureec/LocalScribe/releases/latest/download/LocalScribe.zip)

**Нажмите ссылку выше, чтобы скачать приложение. Аккаунт GitHub не нужен.**
Не используйте зелёную кнопку Code или архивы Source code: это файлы инструкции, а не приложение.

**Текущий выпуск: 2.7.1 (90), для тестирования.** [Что изменилось и файлы выпуска](https://github.com/Yureec/LocalScribe/releases/latest).

> **Известные проблемы этой версии:** при редактировании после диктовки возможны случайные действия меню, некорректная замена текста и ошибки отпускания правого Command. Исправления ещё не включены. Для первого теста используйте несекретный пробный текст, результат проверяйте перед отправкой. Одновременная работа локальной модели может замедлять диктовку.

## 1. Проверьте свой Mac

- Процессор **Apple M1, M2, M3, M4 или более новый Apple Silicon**. Эта сборка не предназначена для Intel.
- **macOS 14 Sonoma или новее**.
- Подключение к интернету для первоначальной загрузки моделей и обновлений.
- Свободное место: приложение — около 100 МБ после распаковки; модели скачиваются отдельно и могут занимать несколько гигабайт. Размер указан в каталоге.

Посмотреть процессор и версию системы: меню Apple  → «Об этом Mac».

## 2. Установите приложение

1. Нажмите **«Скачать LocalScribe для Mac»** в начале страницы.
2. Откройте скачанный `LocalScribe.zip` двойным щелчком.
3. Перетащите **LocalScribe.app** в папку **«Программы» (Applications)**.
4. Откройте LocalScribe из «Программ».

Приложение пока не имеет Developer ID и нотариального заверения Apple. Если macOS блокирует первый запуск, после попытки открытия перейдите в **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о LocalScribe и нажмите **«Всё равно открыть»**, затем подтвердите запуск. Названия могут немного отличаться между версиями macOS. [Инструкция Apple](https://support.apple.com/102445).

Не отключайте защиту macOS целиком. Если запуск не удаётся, отправьте разработчику точный текст сообщения.

## 3. Разрешите запись и диктовку

1. Откройте настройки LocalScribe.
2. При первом использовании записи разрешите доступ к **микрофону**.
3. Для системной диктовки включите её в **Настройки → Общие** и выберите **правый Command**.
4. Для вставки текста разрешите LocalScribe доступ в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. Если система просит повторный запуск, завершите и откройте приложение снова.

Микрофон нужен для записи голоса, Универсальный доступ — для вставки результата в активное поле. Для обычного импорта аудиофайла системная диктовка не обязательна.

## 4. Загрузите модели

Модели не входят в архив приложения. Откройте **Настройки → Модели** и дождитесь окончания выбранной загрузки.

| Для чего | Что установить |
| --- | --- |
| Диктовка по правому Command | **GigaAM-v3** — модель распознавания речи |
| Распознавание файлов | Выбранный движок распознавания и его модель из каталога |
| Полировка текста и действия после диктовки | Встроенную локальную LLM: **Qwen3** или **GigaChat**, затем выбрать её для локальной обработки |

**GigaAM и GigaChat — разные модели:** первая распознаёт звук, вторая обрабатывает уже полученный текст.

Для первого знакомства начните с GigaAM и короткой записи. Qwen занимает меньше памяти, чем GigaChat. Загрузка GigaChat на Mac с 16 ГБ зависит от текущей нагрузки; ожидание ресурсов не означает повреждение установки. Приложение не должно незаметно выбирать другую модель.

При загрузке нужны интернет и место на диске. После установки локальные модели работают без отправки текста облачному AI. Отдельно настраиваемые облачные функции анализа могут передавать текст выбранному провайдеру; не включайте их, если хотите работать только локально.

## 5. Проверьте работу

1. Откройте TextEdit и создайте пустой документ.
2. Нажмите и удерживайте выбранный правый Command, произнесите короткую фразу и отпустите клавишу.
3. Дождитесь появления текста. Проверьте числа, имена и отрицания.
4. Всплывающие подсказки после диктовки сохранены, но в этой версии ещё есть описанные выше проблемы редактирования. При странном поведении прекратите правку этого фрагмента и сообщите разработчику, какие клавиши нажимали.
5. Отдельно импортируйте небольшой аудиофайл и проверьте распознавание.

Не нужно закрывать привычные приложения ради тестирования: сообщите, если LocalScribe заметно мешает обычной работе.

## 6. Получайте обновления

**GitHub-аккаунт и token не нужны.** Приложение проверяет этот публичный канал, скачивает только опубликованные выпуски и проверяет цифровую подпись и целостность архива.

В **Настройки → Общие → Безопасные обновления**:

1. Включите «Автоматически проверять обновления» либо нажмите «Проверить обновления».
2. Когда новая версия доступна, нажмите «Скачать и установить».
3. Дождитесь установки и перезапуска, затем проверьте номер версии.

Обычные коммиты разработчика не рассылаются пользователям. Автоматические проверки ограничены интервалом после успешной проверки; скачивание и установка требуют нажатия кнопки. На момент первого выпуска более новой версии может ещё не быть — это нормально.

Если приложение было получено раньше версии 2.7.1, установите этот ZIP вручную, чтобы перейти со старого приватного канала. После этого обновления будут проверяться здесь.

## 7. Сообщите о результате теста

[Создать сообщение об ошибке](https://github.com/Yureec/LocalScribe/issues/new?template=bug_report.md).
Укажите модель Mac и объём памяти, версию macOS и LocalScribe, выбранную модель, шаги и результат. Для ошибок загрузки — название модели и текст ошибки; для обновлений — исходную и новую версии.

**Issues публичные. Не прикладывайте личные записи, рабочие переписки, пароли, токены и полные журналы с чувствительными данными.** Приватные примеры передавайте разработчику отдельно согласованным способом.
