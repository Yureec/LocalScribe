# От записи до готового текста

[← Скачать и установить LocalScribe](../README.md)

Руководство для тестового выпуска **2.7.1 (90)**. Здесь описана расшифровка записей внутри приложения. Диктовка по правому Command вставляет текст в другое приложение и имеет отдельные [известные ограничения](../README.md).

## 1. Подготовьте модель распознавания

Откройте **Настройки → Модели**. Выберите модель распознавания речи, запустите установку и дождитесь готовности. Скачивание и проверка файлов могут занять время: достигнутые 100% загрузки ещё не означают завершение подготовки.

| Модель | Для чего доступна в LocalScribe |
| --- | --- |
| GigaAM-v3 | Русская речь; также используется для системной диктовки |
| Whisper large-v3 | Многоязычная расшифровка файлов |
| Whisper large-v3-turbo | Другой вариант Whisper, ориентированный на ускоренное распознавание |
| Parakeet TDT 0.6B v3 | Альтернативный движок для расшифровки файлов |
| Qwen3-ASR-1.7B | Распознавание речи с отдельной подготовкой локального окружения |

Не нужно устанавливать всё сразу. Для первой русскоязычной записи можно начать с GigaAM. Сравнивать модели полезно на одном и том же фрагменте: результат зависит от языка, дикции, фонового шума и одновременной речи. Обещать одинаковую точность и скорость на любом Mac нельзя.

**Qwen3-ASR распознаёт звук, а Qwen3 в разделе локального агента работает с текстом. GigaAM и GigaChat тоже решают разные задачи.** Языковая модель не нужна для обычной расшифровки.

Если установка прервалась, вернитесь в «Модели» и используйте предложенное продолжение подготовки. В окне импорта доступны только подготовленные движки.

## 2. Добавьте источник

### Аудио или видео на Mac

Нажмите **«Добавить файлы»**, откройте вкладку **«Файлы»** и выберите запись либо перетащите её в область импорта. Можно добавить несколько файлов: каждый будет обработан через очередь. Добавление следующей партии не отменяет текущую обработку.

Для первого знакомства достаточно короткой записи с понятной речью. Видео можно расшифровывать так же, как аудио; в проекте доступен видеопросмотр.

### Новая запись с микрофона

Откройте экран записи или выберите **«Начать запись микрофона»** в меню приложения в строке меню macOS. Разрешите доступ к микрофону. Закончив, нажмите **«Остановить и расшифровать»** — запись поступит в обработку.

Системная диктовка и обычная запись не могут одновременно захватывать микрофон. Это запись выбранного микрофона, а не прямой захват звука Zoom, браузера или всей системы.

### Ссылка на запись

В окне импорта выберите **«URL / YouTube»**. Можно добавить прямую HTTP(S)-ссылку на аудио или видео. Для YouTube/Vimeo приложение предложит отдельно установить помощник загрузки. Доступность конкретного материала зависит от источника и его ограничений.

При импорте по ссылке файл сначала скачивается на Mac, затем распознаётся локально. Для скачивания нужен интернет.

## 3. Выберите параметры

- **Язык.** Оставьте автоопределение либо укажите известный язык записи. Для GigaAM используйте русскую речь.
- **Модель распознавания.** Выберите один из установленных движков.
- **Разделение по спикерам (диаризация).** Включите для разговора нескольких людей. Может понадобиться отдельная модель из настроек. Программа разделяет голоса, но не узнаёт имена участников из самого факта включения этой функции.
- **Временные метки слов.** Если они нужны, включите соответствующую настройку. Они помогают переходить к отдельным словам и следить за текстом при воспроизведении; доступность зависит от движка и результата обработки.
- **Полировка.** Необязательная локальная обработка текста после распознавания. Для сравнения с оригинальным результатом начните без неё.
- **Саммари, темы и предложение названия.** Необязательные действия после расшифровки. Перед включением проверьте выбранного AI-провайдера в настройках.

Запустите обработку. Разделение спикеров и дальнейшая обработка текста добавляют время к распознаванию.

## 4. Следите за очередью

В **«Очереди»** отображаются этап, прогресс, время работы, модель и язык. Файлы обрабатываются последовательно. Процент распознавания отражает выполненную работу; загрузка модели, подготовка файла и завершающие этапы также занимают время.

Ненужную задачу можно отменить. Если возникла ошибка, откройте её описание и журнал; после устранения причины используйте повторную попытку. При нехватке памяти задача может ждать ресурсов или завершиться сообщением о невозможности запуска. Ожидание можно отменить — переустанавливать модель только из-за ожидания не нужно.

Скорость зависит от модели, длины записи и текущей нагрузки Mac. Установка большой модели на диск не означает, что ей всегда хватит оперативной памяти для работы. В тесте оставляйте свои обычные приложения открытыми и сообщайте, если обработка мешает работе.

## 5. Проверьте расшифровку по записи

После завершения откройте проект из очереди или **«Библиотеки»**. Текст сгруппирован в блоки с временными диапазонами и обозначениями спикеров.

1. Включите воспроизведение рядом с нужным фрагментом и сравните текст с голосом.
2. Используйте перемотку на 10 секунд, скорость воспроизведения и временную шкалу.
3. При наличии временных меток двойной щелчок по слову переносит воспроизведение к нему.
4. Через значок поиска найдите имя, термин или фразу в проекте. **⌘⇧F** открывает поиск по всей библиотеке с переходом к найденным фрагментам.
5. Исправьте текст в режиме редактирования блока. Особенно внимательно проверьте имена, числа, даты и отрицания.

Исходная запись остаётся опорой для проверки. Тихая речь, музыка, перебивания и похожие голоса могут приводить к ошибкам даже при внешне гладком тексте.

### Спикеры

В разделе **«Спикеры»** можно уточнить имена, добавить недостающего участника и исправить принадлежность реплики в режиме редактирования. Для подходящих проектов показывается распределение времени речи.

Сохранённые голосовые профили могут давать предложения совпадений; их нужно подтвердить или отклонить. Простое переименование спикера не обучает голосовой профиль. Перекрывающуюся речь и короткие реплики проверяйте по аудио: ручная оценка качества распознавания спикеров в этом выпуске ещё не завершена.

### Повторяющиеся термины

В **Настройки → Словарь** добавьте пару «как распознано → как должно быть», например для специального термина. Включённые замены применяются при обработке. Уже готовые проекты не переписываются автоматически: для них нужна повторная обработка. Избегайте слишком общих замен, которые могут затронуть другие слова.

## 6. Отредактируйте и обработайте текст

### Локальная полировка

Установите и выберите встроенную языковую модель **Qwen3** или **GigaChat**, затем используйте **«Полировка»** в проекте. Доступны режимы исправления пунктуации, очистки речевых оговорок и стилистической правки. Длинный текст обрабатывается частями с учётом контекста модели.

Полировка работает локально и не переключается на облако при ошибке. Она может изменить формулировки, поэтому результат нужно сверять с записью. Проверки в приложении снижают риск нежелательных изменений, но не гарантируют сохранения каждого нюанса смысла.

**«Отменить последнюю полировку»** позволяет вернуть сохранённый вариант в текущем сеансе приложения. Это не постоянная история версий: перед большой правкой экспортируйте исходную расшифровку. После изменения текста прежние пословные метки могут стать недоступны, поскольку уже не соответствуют новым словам.

### Саммари и итоги встречи

Откройте **«Саммари»**. Выберите подходящий шаблон запроса или настройте свой, чтобы получить краткое содержание, договорённости или задачи. Полезно указывать желаемый формат и просить отмечать неясности. Проверяйте имена исполнителей, сроки и формулировки решений по исходным репликам.

**Провайдер саммари настраивается отдельно от полировки.** Встроенная локальная модель работает на Mac; облачные варианты отправляют текст выбранному провайдеру. Для полностью локального сценария выберите встроенного локального агента. Наличие локального распознавания само по себе не делает облачное саммари локальным.

## 7. Сохраните результат

Нажмите **«Экспорт»** в проекте.

| Формат | Когда выбирать |
| --- | --- |
| TXT | Обычный текст для чтения и дальнейшей правки |
| Markdown | Текст для редактора заметок с поддержкой Markdown |
| SRT / VTT | Субтитры с временными интервалами |
| JSON | Структурированные данные для дальнейшей обработки |

Настройте включение спикеров и временных меток, при необходимости — экспорт выбранных сегментов. Пословные метки доступны только там, где они получены и поддерживаются форматом. Сохраните файл или скопируйте результат в буфер обмена.

В диалоге есть шаблоны, в том числе «Для ChatGPT», «Субтитры», «Протокол встречи», «Саммари» и «Задачи». Шаблон экспорта не заменяет проверку содержимого и сам по себе не является новым AI-анализом. «Для ChatGPT» подготавливает текст для самостоятельного использования; экспорт не отправляет его в ChatGPT автоматически.

## Если что-то не получилось

| Ситуация | Что проверить |
| --- | --- |
| Нужной модели нет в импорте | Завершены ли установка и проверка в «Моделях» |
| Нет записи с микрофона | Разрешение macOS и выбранный источник звука; не занята ли записью системная диктовка |
| Перепутаны участники | Прослушайте спорный участок и исправьте спикера вручную |
| Распознавание ошибается | Язык, слышимость речи, перекрытия; сравните тот же фрагмент другим установленным движком |
| Обработка долго ждёт | Текущий этап, сообщение о памяти и нагрузку Mac; ненужную задачу можно отменить |
| После полировки изменился смысл | Верните последнюю полировку в текущем сеансе и сообщите о примере разработчику приватно |

[Сообщить об ошибке](https://github.com/Yureec/LocalScribe/issues/new?template=bug_report.md): укажите версии приложения и macOS, модель Mac, память, движок и шаги. Публичные Issues видны всем — не размещайте там личные записи и полные расшифровки.
